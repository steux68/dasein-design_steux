# dasein-design website prototype

Desktop prototype of the dasein-design "BIG STRIPES" layout, built directly from the Figma file's design data
(exact positions, text styles, colours and images).

Live: https://steux68.github.io/dasein-design_steux/

- `index.html` – the site (fixed side bars and tabs, pages scroll and snap underneath)
- `figma.css` – styles compiled from the Figma export
- `img/`, `fonts/` – images from Figma and the Calibri-compatible font Carlito
- `tools/` – scripts used to convert the Figma export
